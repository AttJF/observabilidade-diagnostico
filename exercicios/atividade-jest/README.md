# Laboratório — Testes automatizados com Jest

Projeto das atividades de testes automatizados com Jest, com testes de soma, subtração, montagem de operações e exemplos de matchers.

## Começar

Requer Node.js 18 ou superior e npm. Na raiz do repositório:

```bash
cd exercicios/atividade-jest
npm ci
npm test
npm run typecheck
```

Este laboratório tem package.json, lockfile e configuração próprios. O comando npm test na raiz continua executando os testes de observabilidade; execute os comandos acima nesta pasta.

## Perguntas e entrega

As perguntas e respostas estão em [entrega/perguntas.md](entrega/perguntas.md).

Confira a execução:

```bash
npm test
npm run typecheck
```

Para a entrega final, copie a saída real de `npm test` para a entrega ou faça uma captura de tela, conforme o enunciado.

Versione os fontes e package-lock.json; node_modules não deve ser entregue. O .gitignore do repositório já exclui essa pasta.
