MÓDULO DE TESTES AUTOMATIZADOS
Atividades Práticas — Testes Automatizados
com Jest
Introdução aos testes, configuração do Jest e primeiros testes unitários
Vamos colocar em prática o que aprendemos
Estas três atividades acompanham os tópicos 1 a 3 do módulo. Cada uma retoma o conteúdo visto
em aula e pede que você construa a sua própria versão: primeiro classificando os tipos de teste,
depois configurando o Jest do zero e, por fim, escrevendo casos de teste com o padrão AAA.
Objetivos
• Compreender a diferença entre testes unitários, de integração e end-to-end.
• Configurar o Jest em um projeto Node.js com TypeScript.
• Escrever testes unitários para funções puras usando describe, it, expect e matchers.
• Aplicar o padrão Arrange, Act e Assert na organização de cada caso de teste.
• Adotar boas práticas de nomeação e independência entre testes.
As atividades

Atividade 1 — Qual o tipo de teste?
Objetivo: classificar situações reais de um sistema de e-commerce nos três tipos de teste estudados,
justificando cada escolha.
Contexto
Você está desenvolvendo um sistema de e-commerce com as seguintes etapas:
1. O usuário adiciona produtos ao carrinho
2. Calcula o frete e o total da compra
3. Faz login
4. Escolhe a forma de pagamento
5. Finaliza o pedido, que é salvo no banco e notifica o sistema de entrega
Relembrando
Tipo Escopo Velocidade Custo
Unitário Uma função ou método isolado Rápido Baixo
Integração Comunicação entre módulos Médio Médio
End-to-End Fluxo completo do usuário Lento Alto

Atividade 2 — Configurando o Jest do zero
Objetivo: instalar e configurar o Jest em um projeto Node.js com TypeScript, criar a estrutura de
pastas recomendada e confirmar que a suíte roda.
Passo 1 — Crie o projeto
$ mkdir atividade-jest && cd atividade-jest
$ npm init -y
$ npx tsc --init
Passo 2 — Instale o Jest
$ npm install --save-dev jest ts-jest @types/jest
O pacote ts-jest é o que permite ao Jest executar arquivos TypeScript. O @types/jest traz a tipagem de
describe, it e expect para o editor.
Passo 3 — Adicione o script de teste
No package.json, dentro de scripts:
"scripts": {
 "test": "jest"
}
Passo 4 — Gere o arquivo de configuração
$ npx ts-jest config:init
O comando cria o jest.config.js na raiz do projeto. Confira se o conteúdo ficou assim:
const { createDefaultPreset } = require("ts-jest");
const tsJestTransformCfg = createDefaultPreset().transform;
/** @type {import("jest").Config} **/
module.exports = {
 testEnvironment: "node",
 transform: {
 ...tsJestTransformCfg,
 },
};

O Jest reconhece automaticamente as duas convenções. Escolha uma e justifique sua escolha na

Passo 6 — Crie a função e o primeiro teste
// src/sum.ts
export function sum(a: number, b: number): number {
 return a + b;
}
// src/sum.spec.ts
import { sum } from './sum';
describe('sum function', () => {
 it('should add two numbers correctly', () => {
 const result = sum(2, 3);
 expect(result).toBe(5);
 });
});

Atividade 3 — Criando seu próprio teste
Objetivo: criar uma função de subtração e escrever casos de teste para ela usando o Jest,
organizando cada teste no padrão Arrange, Act e Assert.
Relembrando o padrão AAA
Etapa Significado Ação
Arrange Preparar Definir dados e contexto do teste.
Act Executar Chamar a função ou método sob teste.
Assert Verificar Confirmar que o resultado é o esperado.
Passo 1 — Crie a função
No mesmo projeto da atividade 2, crie o arquivo src/subtract.ts com uma função que receba dois
números e devolva a diferença entre eles. Use tipagem explícita nos parâmetros e no retorno, como
foi feito na função sum.
// src/subtract.ts
export function subtract(a: number, b: number): number {
 // escreva a implementação
}
Passo 2 — Escreva o primeiro caso de teste
Crie src/subtract.spec.ts seguindo o modelo abaixo. Note os três comentários: eles marcam as etapas
do padrão AAA e devem aparecer em todos os seus testes nesta atividade.
// src/subtract.spec.ts
import { subtract } from './subtract';
describe('subtract function', () => {
 it('should subtract two positive numbers correctly', () => {
 // Arrange
 const a = 10;
 const b = 4;
 // Act
 const result = subtract(a, b);
 // Assert
 expect(result).toBe(6);
 });
});

Passo 4 — Explore outros matchers
Crie a função montarOperacao(a, b) que devolve um objeto com os campos operacao, valores e
resultado. Escreva testes usando os matchers adequados a cada situação.
Situação Matcher
Comparar um número ou texto exato toBe()
Comparar um objeto ou array pelo conteúdo toEqual()
Verificar se o valor é verdadeiro toBeTruthy()
Verificar se o valor é nulo toBeNull()
Verificar se um array contém um item toContain()
Atenção: toBe compara igualdade exata. Para objetos e arrays, o matcher correto é toEqual.
Passo 5 — Aplique as boas práticas
• Teste uma única responsabilidade por bloco it.
• Use nomes claros e descritivos: o texto do it deve ler como uma frase completa.
• Mantenha os testes independentes entre si, sem depender da ordem de execução.
• Evite lógica complexa dentro do teste: nada de if, for ou cálculos no corpo do it.
• Agrupe os testes da mesma função em um único describe.
